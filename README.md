# 🌐 Tanmay Paliwal — Developer Portfolio

A modern, responsive, and animated portfolio website built using **React + Vite** to showcase my projects, skills, and achievements as a Computer Science student at NMIMS Indore.  

## 🚀 Features

- ⚡ **Fast and Optimized** — Built with Vite for lightning-fast performance  
- 🧩 **Reusable Components** — Modular React structure for scalability  
- 🎨 **Modern UI** — Clean dark-themed interface with smooth animations  
- 📱 **Fully Responsive** — Works seamlessly across all devices  
- ✉️ **Contact Form** — Integrated backend for direct message handling  
- 🧠 **Projects Section** — Showcases my top web and app development projects  
- 💼 **About Me** — Brief overview of my journey, education, and technical skills
